# LPG容器 屋外置場 在庫管理アプリ (Google Apps Script)

LPG容器(ボンベ)を保管する屋外の各置場について、容器サイズ(20kg/30kg/50kg)ごとの
実績数(現在の在庫数)とMAX収容数をGoogleスプレッドシートで管理し、検索・閲覧、
実績数の更新、新規置場の登録ができるWebアプリです。

既存の「容器置場可能数」管理Excel(置場番号ごとにサイズ別 実績/MAX を持つ表)の
構成に合わせて設計しています。

## 構成

- `Code.gs` — Webアプリのエントリーポイント(`doGet`)と、クライアントから呼び出すAPI関数
  (`getInventory` / `addLocation` / `updateLocation`)
- `SheetService.gs` — スプレッドシートの読み書きを行うヘルパーと初期データ(`SEED_LOCATIONS`)
- `Index.html` / `JavaScript.html` / `Stylesheet.html` — UI
- `appsscript.json` — マニフェスト

## データ構造

初回アクセス時に自動でスプレッドシートとシート「置場容量」が作成され、
以下の列が用意されます。既存Excelの主要な置場データ(①〜㉛など36件)を
初期データとして取り込み済みです。

| 列 | 内容 |
|---|---|
| 番号 | 置場番号(①、⑦-1 など) |
| 置場名 | 例: 駐車場、大型製缶、コンテナ |
| 位置 | 例: 南、北・北、西１ |
| 20kg_実績 / 20kg_MAX | 20kg容器の現在数 / 最大収容数 |
| 30kg_実績 / 30kg_MAX | 30kg容器の現在数 / 最大収容数 |
| 50kg_実績 / 50kg_MAX | 50kg容器の現在数 / 最大収容数 |
| 備考 | 例: 雪置場（▲300） |
| 更新日時 / 更新者 | 更新のたびに自動記録 |

各置場は基本的にどれか1サイズのみMAXが設定されていますが、複数サイズを
併用する置場があっても列はそのまま使えます。

## 主な機能

- 番号・置場名・位置・備考によるキーワード検索
- 「満杯に近い置場のみ(80%以上)」フィルタで、容量を圧迫している置場をすぐ確認
- 各置場の実績数・MAX・位置・備考の編集(保存時に更新日時/更新者を自動記録)
- 新規置場の登録(番号重複チェック、マイナス値・置場名未入力を防止)
- 実績数・位置・備考などの変更履歴を「変更履歴」シートに自動記録(地図上のピン位置調整は対象外)
- 容量超過(100%以上)の置場をまとめて毎日メール通知(任意、設定手順は下記)
- 敷地レイアウト表示(地図)上でピンの位置・建物の位置/向き/大きさ・自由なエリア囲み枠をドラッグ編集

## セットアップ手順

### 1. Apps Scriptプロジェクトを用意する

- [script.google.com](https://script.google.com) で新規プロジェクトを作成し、
  プロジェクトのスクリプトID(プロジェクトの設定画面で確認できます)を控える。

### 2. clasp でこのフォルダをpushする

```bash
npm install -g @google/clasp
clasp login

cd lpg-inventory-app
cp .clasp.json.example .clasp.json
# .clasp.json の scriptId を手順1で控えたIDに書き換える

clasp push
```

### 3. Webアプリとしてデプロイする

```bash
clasp deploy
```

または Apps Script エディタの「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」から行います。

- 実行するユーザー: 「デプロイを実行するユーザー」(`appsscript.json` の設定)
- アクセスできるユーザー: 既定は「同一ドメイン内」。社外の人も使う場合は
  デプロイ設定で「全員」に変更してください。

デプロイ後に発行されるURLにアクセスすると在庫管理画面が開きます。

### 4. 保存先スプレッドシートを指定したい場合(任意)

何もしなければ初回アクセス時に新規スプレッドシートが自動作成され、
初期データ(既存Excelから取り込んだ置場一覧)が書き込まれます。
既存のスプレッドシートを使いたい場合は、Apps Scriptエディタの
「プロジェクトの設定」→「スクリプト プロパティ」で

- キー: `SPREADSHEET_ID`
- 値: 使用したいスプレッドシートのID

を追加してください(この場合、指定したスプレッドシートに「置場容量」シートが
自動で作られます)。

### 5. 容量超過メール通知を有効にする(任意)

置場のいずれかが満杯(100%以上)になった場合に、毎日決まった時刻(8時、Asia/Tokyo)に
まとめてメール通知する機能があります。使うには以下を1回だけ行ってください。

1. Apps Scriptエディタの「プロジェクトの設定」→「スクリプト プロパティ」で
   - キー: `NOTIFY_EMAIL`
   - 値: 通知を受け取りたいメールアドレス
   を追加する(またはエディタで `setNotifyEmail('you@example.com')` を1回実行する)
2. エディタで `setupDailyNotificationTrigger` 関数を1回実行し、毎日実行するトリガーを登録する

`NOTIFY_EMAIL` を未設定のままにしておけば、通知は送信されません(トリガーが動いても何もしません)。

## 初期データについて

`SheetService.gs` の `SEED_LOCATIONS` は、ユーザーからいただいた既存の
「容器置場可能数」Excel(2021/02時点のスナップショット)を基に作成した
初期データです。置場の新設・廃止や実績数の変化に合わせて、アプリの
編集画面またはスプレッドシート上で直接更新してください。
